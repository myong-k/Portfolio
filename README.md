# MIN K. 포트폴리오 웹사이트

Figma 시안(`포폴_22561002_강민경`)의 세 프레임을 그대로 옮긴 반응형 웹사이트입니다.
빌드 과정 없이 HTML·CSS·JS 파일만으로 동작하므로, 이 폴더를 그대로 올리면 바로 열립니다.

## 들어 있는 것

| 파일·폴더 | 내용 |
|---|---|
| `index.html` | 메인 (Main 프레임) |
| `storytelling.html` | 10 STORYTELLING 상세 페이지 |
| `diptyque.html` | DIPTYQUE : MEMORY 상세 페이지 (`신규 콘텐츠` 프레임) |
| `css/style.css` | 전체 스타일 |
| `js/main.js` | 페이지 전환, 스크롤, 필터, 마우스 인터랙션 |
| `assets/` | 이미지, 도형 SVG, 폰트 |

## 미리 보기

`index.html`을 Chrome이나 Safari로 열면 바로 볼 수 있습니다.
일부 브라우저(예: Firefox)는 파일을 직접 열었을 때 폰트 파일을 막을 수 있어서, 시안과 똑같은지 확인할 때는 아래처럼 GitHub Pages에 올린 주소로 보는 것이 가장 정확합니다.

## GitHub Pages로 배포하기

1. github.com에서 **New repository**로 새 저장소를 만듭니다.
   - 이름을 `portfolio`로 하면 주소는 `https://아이디.github.io/portfolio/`가 됩니다.
   - 이름을 `아이디.github.io`로 하면 주소는 `https://아이디.github.io/`가 됩니다.
   - 무료 계정은 **Public** 저장소에서만 Pages를 쓸 수 있습니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - 폴더(`MINK-portfolio-web`) 자체가 아니라 그 **안에 있는 것들**을 올려야 `index.html`이 저장소 맨 위에 놓입니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main**과 **/ (root)**로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 표시됩니다.

모든 링크와 이미지 경로가 상대 경로라서 `/portfolio/` 같은 하위 주소에서도 그대로 동작합니다.
나중에 수정할 때는 바뀐 파일만 같은 방법으로 다시 올리면 덮어써집니다.

## 화면 크기

- Figma 프레임 너비(1440px)를 기준으로, 창 너비에 비례해 전체가 커지고 작아집니다.
- 1440px 창에서 시안과 같은 크기이고, 1920px까지 커진 뒤 그보다 넓은 화면에서는 가운데에 놓입니다.
- 767px 이하(휴대폰)에서는 한 줄로 쌓이는 모바일 배치로 바뀝니다.

## 폰트

`assets/fonts/`에 시안에 쓰인 폰트가 들어 있습니다.

| 폰트 | 쓰인 곳 |
|---|---|
| Pretendard | 본문 (OFL 라이선스, 자유롭게 배포 가능) |
| SF Pro Display | 로고, 메뉴, 큰 제목, 프로젝트 목록 |
| Diptyque | DIPTYQUE 웹 쇼잉 안의 글자 |

SF Pro Display는 Apple 라이선스상 웹사이트에 넣어 배포하는 것이 허용되지 않고, Diptyque는 브랜드 전용 서체입니다.
Public 저장소에 올리면 이 폰트 파일들을 누구나 내려받을 수 있다는 점을 알고 올려 주세요.
빼고 싶다면 두 폰트 파일과 `css/style.css` 맨 위의 해당 `@font-face`를 지우면 됩니다. 이 경우 Mac에서는 시스템 폰트(SF Pro), 다른 기기에서는 비슷한 대체 폰트로 보입니다.

## 웹에서 추가한 동작

Figma 프로토타입의 페이지 이동, 호버 상태, 스크롤 이동은 그대로 옮겼고, 웹에서만 다음 동작을 더했습니다.

- 메인: 마우스에 따라 움직이는 히어로 도형, 프로젝트 목록 미리보기 이미지, 카드 VIEW 원, CONNECT 클릭 시 이메일 복사
- 상세 페이지: 상단 진행 바, 포스터 01·02에 마우스를 올리면 정렬과 어긋남이 바뀌는 효과, 웹 쇼잉 문장 회전
- 공통: 스크롤할 때 내용이 올라오며 나타나는 효과, 스크롤 방향에 따라 숨고 나타나는 상단 메뉴

기기에서 "동작 줄이기"를 켜면 움직임 없이 시안 그대로 보입니다.
